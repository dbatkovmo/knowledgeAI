# KnowledgeAI — инструкции агентам разработки

## Назначение
Демонстрационный консультант по русскоязычной базе знаний компании. Текущий движок — детерминированный локальный поиск с цитатами. **Это не LLM и не полноценный RAG**. Не выдавай алгоритм поиска за генеративный AI.

## Контекст
`README.md` → `PROJECT_STATUS.md` → `TASKS.md` → соответствующий модуль. `src/knowledge.js` — документы, поиск и ответы; `src/storage.js` — безопасный локальный импорт и хранение; `src/app.js` — интерфейс; `src/styles.css` — дизайн. Все пользовательские тексты, сообщения, документация и тестовые описания — на русском языке.

## Границы данных
Репозиторий публичный, материал демонстрационный и вымышленный. Не добавляй настоящие корпоративные документы, клиентские персональные данные, секреты, ключи API или удалённую телеметрию. В поисковых ответах включай только сведения, реально найденные в документах; при недостаточных данных всегда указывай отсутствие подтверждения. Импорт заменяет документы только после проверки и подтверждения.

## Проверки
`npm run check` — синтаксис, тесты, статическая сборка. Chromium CI проверяет диалог, источники, каталог и мобильную версию. Не заявляй, что браузерная QA, интеграция LLM, серверная авторизация или развёртывание прошли, если они не выполнялись.
