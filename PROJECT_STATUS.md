# KnowledgeAI — статус проекта

Дата среза: 2026-11-03. Демонстрационное русскоязычное приложение.

Функции: локальная база из 14 вымышленных регламентов, ранжирование по словам на русском языке, консультационный чат с цитатами, отказ от ответа без достаточных источников, поиск и категории, добавление/редактирование/удаление документов, JSON-импорт/экспорт, локальная история диалога.

Система НЕ содержит подключённой языковой модели, embeddings, реального retrieval-augmented generation, сервера или многопользовательских ролей. Для реального бизнеса необходимы разграничение прав, проверка актуальности источников, backend и отдельная LLM-интеграция.
