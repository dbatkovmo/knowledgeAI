# KnowledgeAI — консультант по базе знаний компании

Русскоязычный демонстрационный веб-сервис для поиска проверяемых ответов по внутренним статьям и регламентам организации. Задачи: поиск, чат с источниками, добавление и редактирование статей, управление базой знаний.

Проект разрабатывается как самостоятельный портфолио-продукт `dbatkovmo/knowledgeAI`. Данные и сотрудники вымышлены; личные сведения и коммерческие секреты загружать нельзя.

## Запуск
```bash
npm run dev
npm test
npm run build
```
Node.js 22+; без сторонних зависимостей.

## Важное ограничение
Демонстрационный ответ формируется локальным поисковым механизмом с цитированием найденных материалов. **Это не подключённая языковая модель** и не доказательство полноценного RAG. Для боевого AI-консультанта требуются защищённое серверное подключение LLM, контроль прав доступа и тестирование качества ответов.

## Реализованная демоверсия (3 ноября 2026)

Готовы: чат, поиск по 14 демонстрационным документам, проверяемые источники, история диалога, каталог по категориям, добавление/редактирование материалов, JSON-импорт и экспорт. Все пользовательские тексты на русском языке.

**Автоматические проверки:** синтаксис JS, предметные тесты, сборка и Chromium Desktop/Mobile, включая вопрос с источником и создание нового документа — успешно пройдены в [GitHub Actions](https://github.com/dbatkovmo/knowledgeAI/actions/runs/41653843282).

**Ограничения:** текущая версия не использует языковую модель. Ответы формируются локальным поиском по тексту и снабжаются ссылками на найденные статьи. Это не промышленный RAG, не безопасное корпоративное хранилище и не готовая многопользовательская SaaS-платформа.
