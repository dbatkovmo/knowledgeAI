# KnowledgeAI — консультант по базе знаний компании

Русскоязычный демонстрационный веб-сервис для поиска проверяемых ответов по внутренним статьям и регламентам организации. Задачи: поиск, чат с источниками, добавление и редактирование статей, управление базой знаний.

Проект разрабатывается как самостоятельный портфолио-продукт `dbatkovmo/knowledgeAI`. Данные и сотрудники вымышлены; личные сведения и коммерческие секреты загружать нельзя.

## Запуск
```bash
npm run dev
npm test
npm run build
```
Node.js 22+; без сторонних зависимостей.

## Важное ограничение
Демонстрационный ответ формируется локальным поисковым механизмом с цитированием найденных материалов. **Это не подключённая языковая модель** и не доказательство полноценного RAG. Для боевого AI-консультанта требуются защищённое серверное подключение LLM, контроль прав доступа и тестирование качества ответов.
